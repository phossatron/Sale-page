# Beyond Lab — Landing Page (แก้ไขเนื้อหาได้เอง)

หน้าเว็บ HTML/CSS/JS ล้วน ไม่ต้อง build ไม่ต้องลงอะไรเพิ่ม
**เนื้อหาทั้งหน้าถูกวาดจากข้อมูลชุดเดียว** จึงแก้ข้อความ เปลี่ยนรูป และเพิ่ม/ลบรายการได้ทุกส่วน

> เนื้อหาบนหน้าเว็บ (ทุกข้อความที่ผู้เข้าชมเห็น) เป็น **ภาษาอังกฤษ** ทั้งหมด
> ส่วนแถบเครื่องมือ/โหมดแก้ไข ยังเป็นภาษาไทยเพื่อความสะดวกของผู้ดูแลเว็บ

## วิธีเปิด
```bash
# แนะนำให้เปิดผ่าน local server (เพื่อให้บันทึกข้อมูลลงเบราว์เซอร์ได้สมบูรณ์)
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```
หรือดับเบิลคลิก `index.html` ก็ใช้ได้

## โครงสร้างไฟล์
```
index.html          โครงหน้า + เรียกสคริปต์
css/style.css       สไตล์ทั้งหมด (ตัวแปรสี/ระยะอยู่ที่ :root ด้านบนสุด)
js/content.js       ★ ข้อมูลเนื้อหาทุกส่วนของเพจ (แก้ตรงนี้ได้เลย)
js/icons.js         ชุดไอคอน SVG (เพิ่มไอคอนใหม่ได้)
js/render.js        ตัววาดแต่ละ section จากข้อมูล
js/editor.js        โหมดแก้ไขบนหน้าเว็บ + บันทึก/นำเข้า/ส่งออก
assets/             รูปภาพ (ตอนนี้เป็นรูป placeholder — แทนที่ด้วยรูปจริงได้)
```

## แก้ไขผ่านหน้าเว็บ (ไม่ต้องแตะโค้ด)
กดปุ่ม **✏️ โหมดแก้ไข** ที่แถบเครื่องมือมุมซ้ายล่าง จากนั้น:

| ต้องการ | วิธีทำ |
|---|---|
| แก้ข้อความ | คลิกที่ข้อความ (กรอบประสีส้ม) แล้วพิมพ์ทับได้เลย |
| เปลี่ยนรูป | กดปุ่ม **เปลี่ยนรูป** บนรูป → อัปโหลดไฟล์ หรือใส่ลิงก์ (ดูหัวข้อ "ระบบช่องรูป" ด้านล่าง) |
| เปลี่ยนไอคอน | คลิกที่ไอคอน → เลือกจากชุดไอคอน |
| เพิ่มรายการ | กดปุ่มประ **＋ เพิ่ม...** ใต้แต่ละกลุ่ม |
| ลบรายการ | กดถังขยะที่มุมขวาบนของรายการนั้น |
| สลับลำดับ | กดลูกศรขึ้น/ลง ที่มุมรายการ |
| แก้ฟอร์มติดต่อ | ในโหมดแก้ไข แต่ละช่องจะมีกล่องตั้งค่า: ป้ายกำกับ / ชนิดช่อง / ตัวเลือกของ dropdown |

## ใครเห็นโหมดแก้ไขได้บ้าง
ผู้เข้าชมทั่วไป **ไม่เห็นแถบเครื่องมือเลย** — ระบบถอดออกจากหน้าเว็บตั้งแต่ตอนโหลด
เห็นได้เฉพาะเมื่อ (ก) เปิดจากเครื่องตัวเอง `localhost` / วง LAN / ไฟล์ในเครื่อง
หรือ (ข) เปิดด้วยลิงก์ลับ `?edit=beyond2026` (เปลี่ยนคีย์ได้ที่ `EDIT_CONFIG` ในหัวไฟล์ `js/editor.js`)
กดปุ่ม 🔒 เพื่อล็อกกลับ · ดูรายละเอียดและวิธี build เวอร์ชันที่ไม่มีโค้ดแก้ไขเลยที่ [DEPLOY.md](DEPLOY.md)

## มุมมองผู้เข้าชม (ดูอย่างที่คนอื่นเห็น)
กดปุ่ม **👁 มุมมองผู้เข้าชม** ในแถบเครื่องมือ จะเปิดหน้าเว็บจริงใน iframe โดย**ไม่มีเครื่องมือแก้ไขใด ๆ ปรากฏ**
— เห็นตรงกับสิ่งที่ลูกค้าหรือทีมงานคนอื่นเห็น

- เลือกจำลองขนาดหน้าจอได้: **📱 มือถือ 390×844 · 📲 แท็บเล็ต 820×1180 · 💻 โน้ตบุ๊ก 1280×800 · 🖥 จอใหญ่ 1600×900**
  (เป็น iframe จริง ทำให้ responsive/media query ทำงานตามขนาดนั้นจริง ไม่ใช่แค่ย่อภาพ)
- **⟳ หมุนจอ** สลับแนวตั้ง/แนวนอน · **↻ โหลดใหม่** ดึงเนื้อหาล่าสุดหลังเพิ่งแก้
- **↗ เปิดแท็บใหม่** เปิดหน้าเดียวกันแบบเต็มจอ (URL `?preview=1`) ใช้ส่งให้คนอื่นดูบนเครื่องเดียวกันได้
- ปิดด้วยปุ่ม ✕ หรือกด **Esc**

> **เครื่องมือแก้ไขทั้งหมดถูกสร้างลง DOM เฉพาะตอนอยู่ในโหมดแก้ไขเท่านั้น**
> ออกจากโหมดแก้ไขเมื่อไหร่ ปุ่มขึ้น/ลง/ถังขยะ/เพิ่มรายการ/เปลี่ยนรูป จะหายไปจากหน้าเว็บจริง ๆ
> ไม่ใช่แค่ซ่อนด้วย CSS จึงไม่มีทางโผล่ให้คนนอกเห็น แม้ CSS จะโหลดไม่ทันหรือค้าง cache
>
> เปิดหน้าเว็บด้วย `?preview=1` เมื่อไหร่ แถบเครื่องมือและปุ่มแก้ไขทั้งหมดจะถูกซ่อน
> เหมาะกับตอนนำไปเสนอลูกค้า หรือถ่ายภาพหน้าจอ

ปุ่ม **🚀 เผยแพร่ขึ้นเว็บ** จะ commit เนื้อหาปัจจุบันเข้า GitHub ให้เลย (ใช้ได้จากมือถือ ดู [DEPLOY.md](DEPLOY.md))

ระบบ **บันทึกอัตโนมัติ** ลง localStorage ของเบราว์เซอร์ และมีปุ่ม
`💾 บันทึก` · `⬇️ ส่งออก JSON` · `⬆️ นำเข้า JSON` · `↺ คืนค่าเริ่มต้น`

> ทำเนื้อหาเสร็จแล้วให้กด **ส่งออก JSON** แล้วนำค่าที่ได้ไปวางแทนใน `js/content.js`
> (เปลี่ยนบรรทัดแรกเป็น `window.DEFAULT_CONTENT =` แล้วปิดท้ายด้วย `;`)
> เนื้อหาจึงจะกลายเป็นค่าตั้งต้นของทุกเครื่อง ไม่ใช่แค่เบราว์เซอร์ตัวเอง

## ระบบช่องรูป (image slot) — รูปพอดีกรอบเสมอ
ทุกช่องรูปมีกรอบและสัดส่วนกำหนดไว้ตายตัว รูปใหม่ที่ใส่เข้าไป **ไม่ว่าสัดส่วนใด จะถูกจัดให้พอดีกรอบเดิมเสมอ**
เลย์เอาต์จึงไม่เพี้ยน ไม่ว่าจะอัปโหลดรูปแนวตั้ง แนวนอน หรือจัตุรัส

| ช่องรูป | สัดส่วนกรอบ | ค่าเริ่มต้น | ย่อสูงสุด |
|---|---|---|---|
| โลโก้ | 170 × 48 px | เห็นทั้งรูป ชิดซ้าย | 600 px |
| ภาพพื้นหลัง Hero | เต็มพื้นที่ section | เต็มกรอบ กึ่งกลาง | 1920 px |
| ภาพปกวิดีโอ | 16:9 | เต็มกรอบ กึ่งกลาง | 1600 px |
| ภาพสินค้า (แพ็กเกจ) | 1:1 | เต็มกรอบ กึ่งกลาง | 1000 px |
| ภาพบุคคล (ท้ายเพจ) | 3:4 สูง 340 px | เห็นทั้งรูป ชิดล่าง | 900 px |

เมื่อกด **เปลี่ยนรูป** จะมีหน้าต่างให้:
1. **ตัวอย่างในกรอบจริง** — เห็นผลลัพธ์ตรงกับที่จะแสดงบนหน้าเว็บทันที
2. **ย่อขนาดอัตโนมัติ** — ไฟล์ที่อัปโหลดถูกย่อตามขนาดสูงสุดของช่องนั้น พร้อมบอกว่าย่อจากเท่าไร → เหลือเท่าไร (กัน localStorage เต็ม)
   ไฟล์ SVG/GIF จะไม่ถูกย่อ (คงความคมชัดเวกเตอร์และภาพเคลื่อนไหว)
3. **การจัดวางรูปในกรอบ** — เต็มกรอบ (ครอบตัดส่วนเกิน) / เห็นทั้งรูป (มีขอบว่าง) / ยืดเต็มกรอบ
4. **ตำแหน่งที่ต้องการให้เห็น** — กึ่งกลาง / บน / ล่าง / ซ้าย / ขวา (ใช้ตอนรูปถูกครอบตัด เช่น อยากให้เห็นใบหน้าด้านบน)
5. ปุ่ม **คืนค่าการจัดวางเริ่มต้น** ของช่องนั้น

ค่าการจัดวางที่ปรับเองจะถูกเก็บใน `imageSettings` ของข้อมูล (export/import ไปด้วย)
ส่วนสัดส่วนกรอบของแต่ละช่องแก้ได้ที่ตัวแปร `SLOTS` ในหัวไฟล์ `js/render.js`

## ส่วนต่าง ๆ ของเพจ (ตรงกับ key ใน `js/content.js`)
`header` เมนู · `hero` แบนเนอร์หลัก · `trust` โลโก้ลูกค้า+ตัวเลข · `problems` ปัญหาที่เจอ ·
`services` One Stop Service · `pricing` แพ็กเกจราคา · `about` เกี่ยวกับเรา+วิดีโอ ·
`testimonials` รีวิว · `faq` คำถามพบบ่อย · `contact` ฟอร์มติดต่อ · `floating` ปุ่มลอยด้านขวา · `footer`

## จุดที่ควรต่อยอด
- **ฟอร์มติดต่อ** ตอนนี้เป็นตัวอย่าง (แสดง alert) — ต่อ backend/LINE Notify/Google Sheet ได้ที่ฟังก์ชัน `beyondSubmit()` ใน `js/render.js`
- **รูปภาพ** ใน `assets/` เป็น SVG placeholder ทั้งหมด แทนที่ด้วยรูปจริงชื่อเดิมได้ทันที
- **สีแบรนด์** แก้ที่ `site.brandColor` ใน `js/content.js` หรือ `--brand` ใน `css/style.css`
- **ไฮไลต์สีส้มในหัวข้อ** ใช้ `<span class="hl">ข้อความ</span>` ภายในข้อความได้
